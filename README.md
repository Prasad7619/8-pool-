# 8-pool-
This project is a simple 8 Ball Pool game developed using Python. It simulates basic pool gameplay where the player can aim, adjust power, and strike the cue ball to pocket other balls.

The game includes physics-based ball movement, collision detection, and simple controls for aiming and shooting. It provides an interactive experience similar to a real pool table.

Features
Cue stick aiming system
Ball collision and movement physics
Pocket detection
Simple game interface
Single-player gameplay
Technologies Used
Python
Pygame (for graphics and game mechanics)
Purpose

This project was created to practice game development concepts like physics simulation, user interaction, and graphical rendering using Python.
